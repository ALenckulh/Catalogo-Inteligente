## Formato

Para a monografia final, converter cada entrada para o padrão ABNT:

```
SOBRENOME, Nome. Título do trabalho. [S.l.]: Editora, Ano. ISBN.
```

Para artigos:

```
SOBRENOME, Nome. Título do artigo. Nome do Periódico, v. X, n. Y, p. Z-W, Ano.
```
